# 후속 실험 추천 — 아직 실행하지 않은 제안

## 근거와 우선순위

1단계 초기 macro AUROC 50.21%, 최종 52.02%. 2,001개 구간 중 이상 판정은 7개(0.35%)뿐이며 R01·R02는 모두 0이다. 후처리나 양자화보다 **초기 시각 판정이 왜 거의 항상 정상인지**를 먼저 진단한다. 한 실험에서 질문·시간 창·모델을 동시에 바꾸지 않는다.

| 단계 | 권장 실험 | 고정/변경 요소 | 판단 자료 | 상태 |
|---|---|---|---|---|
| 2 | 입력·시각 인식·응답 진단 | 1단계 모델/질문/설정 유지. 8프레임 토큰 연결·색상·순서, 실제 읽힌 프레임, 텍스트 근거, 파싱 성공, 문맥 중복 검사 | 장면/객체/공정 동작을 실제로 인식하는지, 0 판정 원인 분류, hallucination 사례 | 제안 |
| 3-1 | 공정 질문의 효과 | 동일 10초·8프레임·모델에서 공개 UCF 질문 vs 정상 학습 영상만으로 사전 정의한 공정 질문 | 초기 판정/최종 AUROC·AP, 이상 판정률, 정상 FPR, 설명의 영상 근거 | 제안 |

## 2단계부터 권장하는 이유

- 원시 판정이 거의 모두 0이면 retrieval/smoothing만 조정해 안정적인 탐지를 얻기 어렵다.
- 논문/공식 코드와 현재 구현 사이의 다중 이미지 토큰 연결 및 ImageBind frame-list 변환 차이는 구현 진단과 모델 성능 문제를 구별할 이유이다.
- R01은 15개 중 14개 영상이 300프레임 미만이어서 가정 30 FPS에서 10초 창이 넓다. 다만 이 점만으로 실패 원인을 확정하지 않는다.
- 모델이 공정 동작을 못 보는 경우 질문 변경으로 해결될지 불확실하다. 입력/인지 확인 후에 질문·시간 조건을 별도로 비교한다.

## 누수 방지와 성공 판단

- 현재 테스트셋 결과를 이미 관찰했으므로 동일 테스트셋의 다음 비교는 탐색적 결과로 표시한다. 최종 일반화 주장은 새로 분리한 검증 영상/독립 공정 또는 별도 승인된 데이터에서 확인한다.
- 질문 설계와 정상 보정은 정상 학습 자료만 사용한다. 테스트 AUROC로 최적 질문/시간 창을 선택하지 않는다. 비교 구성과 주/보조 지표를 먼저 기록하고 모든 결과를 보고한다.
- 설정을 동결한 다음 seed 1/2 또는 반복 실행을 통해 재현성을 확인한다. 결과를 본 뒤 seed를 고르지 않는다.
- 5단계는 현재 정상-only IPAD 학습 분할만으로 원형대로 수행할 수 없다. IPAD 테스트 이상 영상을 학습에 옮기지 않는다. UCF-Crime 등 새로운 데이터 사용 또는 독립 학습용 이상 데이터 확보가 먼저 필요하다.
- 원 논문은 정상/이상 비디오 라벨을 이용해 질문을 학습하고 validation으로 선택한다. 참조: [VERA v3](https://arxiv.org/html/2412.01095v3), [공식 코드](https://github.com/vera-framework/VERA).

추천 순서는 **2단계 → 3-1/3-2 분리 비교 → 4단계**이다. 5단계는 원형의 질문 학습까지 재현하려는 별도 목표이며 데이터 조건 충족 후 진행한다. 이 문서는 실행 승인이 아니다.
